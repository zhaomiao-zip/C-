# C 语言期中复习工作台

参照 `../C语言复习笔记——来自CC98.pdf` 与 `../notes/` 的专题笔记做的本地复习工具。

## 启动

双击 `启动复习网页.bat`，浏览器会自动打开 `http://127.0.0.1:8765`。

> 期中日期默认是「今天 + 7 天」，打开「今日」页可以改成你的实际考试日期，计划会按剩余天数重新分配。

也可以在终端里：

```bash
cd "E:\ZJU\C language\review-site"
python server.py
```

然后手动打开 `http://127.0.0.1:8765`。

> 编程题的「运行」需要本地 gcc。脚本会自动在 PATH 和常见 MinGW 路径里找；找不到时页面会给出提示。

## 四个部分

- **今日**：距期中倒计时、今天的三件事、自动生成的学习计划（按考试日期和每日时长分配章节）
- **知识**：14 章复习讲义，前 10 章标期中，后 4 章标期末
- **练习**：40 道选择题 / 手算输出 / 代码填空，答完立刻看解析
- **编程**：8 道题，页面内编辑、编译、运行、跑多测试点、逐行对比样例输出、看标准答案

## 数据保存在哪

所有进度存在浏览器 `localStorage` 的 `creview.v1` 键里，不上传。换浏览器或清缓存会丢。

## 文件

```text
index.html   页面骨架
styles.css   设计系统与布局
data.js      14 个知识章节
questions.js 40 道非编程题 + 8 道编程题
app.js       路由、练习、编辑器、判题
server.py    静态服务 + gcc 编译 API
```
